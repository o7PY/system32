    How it works

    Type a selector and press Enter. The game adds this rule to player.css:

    :where(#arena) :is(your selector) {
  display: none;
}

    :where() adds nothing to specificity, so your rule is exactly as strong as your selector, and it only reaches inside the arena.

    Specificity is a triple (ids, classes, tags): #a.b.c div is (1,2,1). Compare left to right; the first bigger number wins. A 🛡 badge shows an enemy's defense.

    Ties go to whoever comes later: you. player.css is loaded after the enemies' stylesheet.

    Don't hide your allies. Inline style="…" beats any selector; only !important beats inline.
