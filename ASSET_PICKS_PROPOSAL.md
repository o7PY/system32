# ASSET_PICKS_PROPOSAL.md: role picks for SpaceSaga (Step 0). Status: approved, built (`tools/assets.json`)

Input: `ASSET_MANIFEST.md` (92 models; generated by `tools/inventory-assets.mjs`) and contact sheets rendered from the raw glTF with three.js 0.186.1 in headless Chrome (`assets/source/_preview/sheets/{chars,low,high,block,items,decor,planets}.png`; the sheets and the tool that made them live under the gitignored `assets/source/`, nothing of it is committed). **Nothing has been built and no game code exists; the stub `games/space-saga/index.html` only serves the shell tests.**

Facts that shape the picks:
- Only the 12 models in `Characters/` are animated (skinned, 18 clips on an astronaut). Everything in `Environment/`, `Items/` and `Vehicles/` is static.
- All 92 models share ONE 5 KB atlas texture (`Atlas.png`, embedded in each glTF), so textures cost nothing; the whole kit is 2.6 MB of glTF buffers for my picks before compression (budget: 6 MB processed).
- Every model faces **+z** (toward a camera at +z). The runner moves toward -z, so characters and anything with a front get `rotY: 180` at build time.
- Sizes are wildly mixed (a rover is 5 m, a crate 0.9 m, an astronaut about 3 m tall in its run pose), so the build normalizes each model to a role-specific target size (below), exactly as the spec says.
