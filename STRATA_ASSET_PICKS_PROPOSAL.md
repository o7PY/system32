All of it is under the gitignored `assets/source/`; the mapping is `tools/strata/assets.json` (every path in it was checked to exist). **Nothing has been built and no game code exists.**
- Contact sheets: `assets/source/_preview/strata/tiles.png`, `items.png`.
- **Audition page (please listen):** run `python3 serve.py`, open `http://localhost:8000/assets/source/_preview/strata/audition.html`. I picked sounds by file name and duration only, I cannot hear them.

## What I found
- The Voxel Pack tiles are **flat 128x128 face textures** (not isometric cubes), so they map straight onto block faces; the build downsamples them to 32x32 with nearest-neighbour. Items are 128x128 icons.
- The pack has **no** bedrock, stick or iron ingot (those are "generate"), but tools exist in bronze, silver, gold, iron and diamond, so the tool tiers need no tinting (see below).
- The pack also ships **sun, moon and cloud art** (`PNG/Other/`), optional for the sky (the spec asks for quads and flat clouds; I can use these or draw them in code).
- Sounds are `.ogg` already (stereo, 44.1 kHz). The picked 62 files are about 470 KB raw, so mono + trim + normalize will land far under the 1.5 MB sound budget.
